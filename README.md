# Squonk Visualisation Designer

This repository holds the **published, built output** of
[`squonk2-viz-components`](https://github.com/InformaticsMatters/squonk2-viz-components) —
there is no source here, only what its `docs.yml` and `gallery.yml`
GitHub Actions workflows push to this branch on release.

- **[User Guide](https://informaticsmatters.github.io/squonk2-viz-docs/latest/)**
  — how to build and use a visualisation page in the Squonk Data Manager app.
- **[Component Gallery](https://informaticsmatters.github.io/squonk2-viz-docs/gallery/)**
  — every visual component, live, shown against example data.
